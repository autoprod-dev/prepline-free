# Prepline (free), v3.4.6

Prepline by Autoprod sorts a kitchen preplist into prep lists by dish, station and team section.
Free and complete: every tool is on. No account, no sign-up, no licence. Open it at https://autoprod-dev.github.io/prepline-free/

- pdf.js, SheetJS and the QR code library are served from this site: no CDN, no web fonts, no analytics,
  no request to any other domain. Your files and lists stay in your browser.
- After the first visit it keeps working offline.
